# Промпт для публикации Noir Chat

```text
Подготовь существующий Noir Chat на Rust для распространения друзьям. Работай на моём ПК, в папке проекта, с уже авторизованным GitHub CLI.

Создай оригинальную чёрно-белую квадратную аватарку с лаконичным знаком чата. Сохрани PNG, сделай из него ICO, примени иконку к Windows EXE и окну приложения и добавь PNG в README.

Проверь сборку, выполни тесты и упакуй Windows x64 EXE вместе с инструкцией запуска и лицензиями зависимостей. Укажи, какие сценарии и ограничения проверены. Для нестабильной сборки используй предварительный релиз.

Опубликуй исходники в отдельном публичном репозитории GitHub и загрузи ZIP в GitHub Releases. Перед публикацией проверь состав коммита и архива. В них должны быть только файлы проекта, без токенов, профилей, личных данных и файлов соседних проектов. Существующие чужие репозитории не меняй. Дай ссылку на проект, прямую ссылку на архив и ссылку на аватарку.

Работай без дополнительных подтверждений для уже разрешённых операций. Если сервис требует личного входа или обязательного подтверждения, продолжи все независимые шаги и сообщи, что именно осталось.
```
